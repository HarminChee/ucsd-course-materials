# UCSD Course Materials

A public archive of my UCSD course folders, excluding `ECE271A`.

This version is intended to preserve the complete course-learning context under the assumption that the relevant instructors permit students to publish and redistribute the official course materials, including slides, problem PDFs, quizzes/exams, and answer PDFs.

## Included Courses

- `CSE227`
- `CSE256`
- `CSE258`
- `ECE251C`
- `ECE253`
- `ECE269`
- `ECE285`

## Excluded

- `ECE271A`, by request.
- Virtual environments, dependency installs, caches, nested `.git` directories, and OS-generated files.
- Obvious private credential files such as `.env`, `.pem`, `.key`, and similarly named secret/credential files.

## Repository Notes

- Large course data files are tracked with Git LFS.
- Some folders contain official course PDFs, assignments, quizzes, exams, and solution PDFs because they are being published under the stated instructor-permission premise.
- Use this material responsibly. If you are currently taking one of these courses, follow the active course policy first.
