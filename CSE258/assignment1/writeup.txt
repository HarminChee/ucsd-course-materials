Task 1 Rating prediction
I use a regularized matrix factorization model with user/item biases, blended with a simple mean baseline. From train_Interactions.csv.gz I build integer indices for users and books, collect all (user, item, rating) triples, and compute the global mean rating as well as per-user and per-item mean ratings. The MF model learns 40-dimensional latent vectors for users and items and bias terms for each user and item. For a given pair, the MF prediction is μ + b_u + b_i + ⟨P_u, Q_i⟩, where μ is the global mean.
Training uses stochastic gradient descent with L2 regularization on embeddings and biases. I randomly split the data into 90% training and 10% validation, shuffle the training triples each epoch, and update parameters to minimize squared error plus regularization. The learning rate starts at 0.004, is halved at epochs 30 and 45, and the regularization strength is 0.04. I track the validation RMSE and keep the parameter set with the best validation performance. At test time, I combine the MF prediction and a user/item mean baseline: final_prediction = 0.7 × MF + 0.3 × baseline_mean, where the baseline uses user and item averages with fallbacks to the global mean. The result is clipped to [1, 5].



Task 2 Read prediction
For the read prediction task, I treat the problem as implicit feedback and train a two-tower neural model with contrastive positive/negative pairs. From train_Interactions.csv.gz I build integer indices for users and items, collect all observed (user, item) pairs as positives, and store for each user the set of items they have interacted with. I randomly split the positive pairs into 90% training and 10% validation.
The model is a two-tower architecture implemented in PyTorch, with 32-dimensional embeddings for users and items, plus user, item, and global bias terms. Given a pair, it computes the dot product between the user and item embeddings, adds the biases, and outputs a single logit; applying a sigmoid yields the probability that the user would read the item. Training uses mini-batch Adam optimization with a binary cross-entropy loss. For each positive pair in a batch, I sample a small number of negative items for the same user that do not appear in the user’s interaction set. The labels for positives are 1 and for negatives are 0. I train for 10 epochs with batch size 4096, learning rate 0.01, and weight decay 1e-5, decaying the learning rate at selected epochs. On the validation set, I generate balanced positive/negative pairs, sweep a probability threshold between 0.3 and 0.7, and choose the threshold that maximizes accuracy; I also keep the model parameters from the best validation epoch. At test time, if a user or item does not appear in the training indices, I predict 0; otherwise, I compute the model probability and compare it with the tuned threshold to output 0 or 1. The predictions are written to csv.



Task 3 Category prediction
The category prediction task is solved with a standard text classification pipeline based on TF-IDF features and multinomial logistic regression. From train_Category.json.gz I extract the review text and the numeric genreID labels, and from test_Category.json.gz I extract the review text together with userID and reviewID. All reviews are lowercased.
I use a TfidfVectorizer over unigrams and bigrams with sublinear term frequency scaling, a maximum of 150,000 features, min_df = 3, and max_df = 0.9. The vectorizer is fit on the training texts to produce a sparse TF-IDF matrix, and then applied to the test texts. For model selection, I perform a stratified 90%/10% train/validation split on the training matrix and labels, and train a multinomial logistic regression classifier (C = 4.0, max_iter = 200, solver = "lbfgs"). After checking the validation accuracy, I retrain the same model on the full training set and apply it to the test TF-IDF features to obtain predicted genreIDs. The output file predictions_Category.csv contains userID, reviewID, and the predicted label for each test example.
